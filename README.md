## 🏥 ANAF Medical Assistant

ANAF Medical Assistant is a C++ console-based project developed as part of an assignment.
It is designed to assist doctors and healthcare professionals by:

1. Collecting patient data

2. Identifying possible symptoms

3. Suggesting appropriate medicines based on the collected information

This project was created to demonstrate the use of C++ programming concepts in a real-world scenario.

### 🚀 Features

Collects and stores patient information

Identifies symptoms from input data

Suggests possible medications for patients

Simple and user-friendly console interface

Demonstrates practical use of C++ logic and decision-making

### 🛠️ Technologies Used

C++ – core programming language

OOP concepts – classes, objects, and functions

Conditional logic – to process patient data and recommend medicines


### 💡 Learning Objectives

This project helped me understand and practice:

Implementing C++ classes and objects

Working with functions and data structures

Applying conditional statements for decision-making

Creating a simple real-world application with C++

#### NB: This project is developed for educational purposes only and is not intended for real medical use.
